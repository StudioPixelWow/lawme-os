# 06 · Attention Blueprint (FROZEN)

What may compete for attention, what never competes, and what is intentionally quiet.
Attention is a scarce budget; the Matter App spends it on exactly one thing at a time.

## The one-competitor rule

At any moment, **one** element owns attention — the single loudest colored object. On
a troubled matter it is the **posture chip** (and the CTA that resolves it, sharing its
color). On a calm matter it is the **one forward CTA**. There is never a tie. This is
the two-accent law applied to attention: gold (structure/meridian/דינו) + one semantic
color (the thing that needs you).

## What is ALLOWED to compete (and only one wins)

Only these can hold the single semantic color, and only the most urgent one does:

1. **Posture chip** — when the matter is not on_track (the color of the state).
2. **The one CTA** — inherits the concern's color when it resolves a blocker; is a
   quiet forward step when the matter is healthy.
3. **An overdue strict deadline** — the strongest object in the language; it may pull
   attention, but its color yields to the posture chip when both are present (the chip
   is the headline; the deadline is *why*).
4. **A ▲ blocked-transition pulse** on the now-node — a single restrained pulse, never
   more than one on screen.

Rule: if two of these are present, the **posture chip wins the color**; the others
drop to ink + shape (label + ◆/▲) so only one thing is loud.

## What NEVER competes

- **The Context Dock** — hairline-seated, ink only; quiet by law. It informs; it never
  shouts. (A deadline in the dock is the *object*, not a color bomb.)
- **The Score rail** — states are shown by position (weakest first) + shape + a single
  called-out segment; the rail never lights up 12 colors (no traffic-light overload,
  forbidden #5).
- **Lens headers** — caption weight, ink; a ⚑/▲ marker signals *where*, never demands.
- **The spine's done/future nodes** — muted ● / dashed ○; only the now-node carries
  the meridian.
- **דינו** — one gold seal on one object; never a toast, never a panel, never a cluster
  of seals. Silence when nothing is actionable.
- **Metadata / freshness / provenance** — micro, faint; present for trust, invisible to
  the glance.
- **Team presence, secondary actions, activity** — all quiet lenses; never permanent
  color.

## What is INTENTIONALLY quiet

- **A healthy matter** — the room rests: green chip, clean spine, no seals, one calm
  forward CTA. The product does not fill silence with widgets (calm-when-calm).
- **Everything the attorney did not ask for** — lenses stay collapsed; Dino's pipeline
  stays unrun; finance stays hidden for unpermitted roles; history stays folded.
- **Success and completion** — a completed stage collapses to a one-line confirmation
  with a completed dot; no celebration, no confetti (forbidden #36).

## Escalation ladder (how attention grows with the matter's real state)

```
 on_track        → chip calm green · one forward CTA · dock silent
 needs_attention → chip amber · one attention concern surfaces · dock still quiet
 at_risk         → chip orange · CTA resolves the risk · ▲/◆ on the node
 blocked         → chip red · CTA clears the blocker · ▲ pulse on the transition
 degraded        → chip grey-red "הערכה חלקית" · a partial-assessment banner (once)
 review_required → a "טעון בדיקה" seal by the chip (quiet, not a color bomb)
```

Attention escalates only as the matter's real state escalates — never manufactured,
never a fixed dashboard of alarms.

## The banner exception (degraded / offline)

A degraded or offline state shows **one** quiet glass banner (top of canvas / in the
command bar) — the single allowed persistent notice. It states the partial-assessment /
offline condition and never blocks the readable work beneath it. No toast storms
(forbidden #33), no full-screen error for a partial failure (forbidden #34).

## The attention test (release gate)

Squint at the screen: exactly **one** thing should be loud, and it must be the thing
the attorney should act on. If two things compete, or if a calm matter looks busy, the
attention budget is overspent and the layout is wrong.
