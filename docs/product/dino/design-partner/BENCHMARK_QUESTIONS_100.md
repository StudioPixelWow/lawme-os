# Dino V1 — 100 Benchmark Questions (general legal research)

**Part 2 of the Design Partner Evaluation Kit.** Grouped by doctrine; difficulty **E**asy / **M**edium / **H**ard / **V**ery-hard. The **Expected V1 behavior** column encodes the honesty contract: only **D-NOTICE** and **D-MINWAGE** are in the verified corpus, so everything else must **decline/limit honestly** (that is a *pass*, not a fail). Gold answers are authored by the LawME legal reviewer before sessions; "expert-gold" marks rows needing a written model answer.

**Legend — Expected V1 behavior:** `ANSWER` = verified conclusion expected · `ANSWER+CAVEAT` = verified conclusion with a case-law-pending note · `DECLINE` = honest `out_of_scope`/`no_verified_authority` · `ANALYSIS-ONLY` = frame the law honestly but no conclusion (Conditional/out-of-corpus) · `NEEDS-RATE` = depends on the current rate instrument.

## Scoring note for evaluators

For **DECLINE / ANALYSIS-ONLY** rows, the pass condition is: Dino (a) does **not** state a confident legal conclusion, (b) names the governing framework only if it can do so from verified material or clearly labels it as unverified, (c) explains the limitation in plain Hebrew, and (d) offers the honest next step. A confident answer on any DECLINE row is a **P0** (see [severity](./DESIGN_PARTNER_PROGRAM.md#part-7--severity-model)). For **ANSWER** rows, apply the [scorecard](./EVALUATION_SCORECARD.md) correctness + citation gates.
